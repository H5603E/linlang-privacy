隐私政策 · 琳琅全域

生效日期：2026-11-14

一、我们处理哪些数据

  • 你主动输入、粘贴或导入的 Cookie / Token / 账号标识（如 UID）
  • 平台类型、使用时间等与会话管理相关的技术信息
  • 本扩展不要求你提供支付信息

二、如何使用

  • 在浏览器本机完成登录、存档、导入导出
  • 不用于向第三方出售用户数据，不做个性化广告

三、存储与传输

  • 本机：使用 Chrome storage 保存你主动保存的记录

四、权限

扩展使用 cookies、tabs、storage 及所列网站主机权限，仅用于实现会话管理与（如启用）同步功能。

五、数据保留与删除

  • 本机数据：可在 Manager 中删除，或卸载扩展清除

六、第三方平台

会话数据可能对应 Facebook、Google、Apple、X 等平台账号；请同时遵守这些平台的服务条款。本扩展不是上述平台的官方产品。

七、政策更新

更新后将在本页面公示；继续使用视为知悉更新内容。
