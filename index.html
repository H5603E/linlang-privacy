隐私政策 · 琳琅全域

生效日期：2026-11-19

一、我们处理哪些数据

  • 你主动输入、粘贴或导入的 Cookie / Token，以及你为存档设置的名称、平台分类等
  • 上述数据仅保存在你的本机浏览器中，由你自行管理
  • 本扩展不会将 Cookie、Token 或其他会话数据上传至开发者或第三方的服务器

二、如何使用

  • 在本机完成登录、写入 Cookie、存档、导入与导出
  • 不用于广告、不出售用户数据、不向第三方提供会话内容

三、存储位置

  • 使用 Chrome 扩展的 storage API 及浏览器 Cookie 存储，数据留在你的设备上
  • 卸载扩展或清除浏览器数据可能导致本地存档丢失，请自行做好导出备份

四、权限说明

扩展申请 cookies、tabs、storage 及各目标网站的主机权限，仅用于：读写对应站点会话、打开或刷新页面、保存你的本地设置与存档记录。

五、删除数据

  • 在扩展 Manager 中删除单条记录，或清空存档
  • 在 chrome://extensions 卸载本扩展

六、第三方平台

你导入的会话可能关联第三方网站账号。请遵守各平台服务条款。本扩展不是这些平台的官方产品。

七、政策更新

更新后在本页面公示。继续使用即表示知悉更新内容。
